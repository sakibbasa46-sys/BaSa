# BaSa - বাসা ভাড়া খুঁজুন সহজে

**BaSa** হলো একটি ফ্ল্যাটার (Flutter) ভিত্তিক মোবাইল অ্যাপ্লিকেশন, যার মাধ্যমে ব্যবহারকারীরা সহজেই বাসা/ফ্ল্যাট ভাড়ার তথ্য দেখতে এবং খুঁজতেও পারবেন।

## 🚀 বৈশিষ্ট্যসমূহ (Features)
- বাসা ভাড়ার তালিকা প্রদর্শন
- নতুন বাসা ভাড়ার বিজ্ঞাপন পোস্ট করা
- লোকেশন ও বাজেট অনুযায়ী ফিল্টার করার সুবিধা

## 🛠️ প্রযুক্তি (Technologies Used)
- **Framework:** Flutter
- **Language:** Dart
- **State Management:** Provider / Riverpod
